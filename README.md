# FiscalShieldAI
财智哨兵 - 地方财政风险智能预警系统

## 项目简介
面向政务部门、企业机构、社会公众三类用户，通过角色适配层实现差异化功能与安全策略的地方财政风险智能预警系统。

## 技术栈
- 后端：Python 3.12 (推理服务) + Python 3.10 (模型训练)
- 前端：Qt 6.10 + C++
- AI模型：ST-GNN(教师) → LightTCN(学生，知识蒸馏)
- 大模型：vivo蓝心大模型 (AIGC比赛官方)
